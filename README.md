# UID – Student E-Portfolio App

A Flutter-based student e-portfolio application that provides a simple and interactive way to view academic details, certifications, extracurricular activities, and achievements.

## ✨ Features

- **Login Page:** Login screen with input validation.
- **Academic Details:** Displays student academic information in a structured table.
- **Course Certifications:** Showcases completed courses and certifications.
- **Extracurricular Activities:** Displays participation in extracurricular activities.
- **Achievements Slideshow:** Automatically plays a slideshow of student achievements.
- **Logout:** Allows users to log out of the dashboard.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **IDE:** Visual Studio Code

## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- Flutter SDK
- Dart SDK (included with Flutter)
- Visual Studio Code
- Flutter and Dart extensions for VS Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Manaswini-2512/UID.git
```

**2. Navigate to the project directory**

```bash
cd UID
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

To run the application in Chrome, use:

```bash
flutter run -d chrome
```
